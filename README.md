# 麻将多面听牌挑战 🀄

一个纯前端（HTML + JavaScript，零依赖）的麻将听牌测验应用：随机给出已听牌的 13 张手牌，玩家从选项牌中**多选**出所有能胡的牌，系统按麻将规则引擎实时判定。

## 规则实现（engine.js）

- **胡牌**：14 张 = 4 组面子（顺子/刻子）+ 1 对将；或 **七对**（4 张相同计两对）；或 **十三幺**。
- **听牌**：13 张手牌，逐一尝试 34 种牌，加一张后能胡即为所"听"。
- **多面听**：听 ≥ 2 种牌（两面听、三面听、双碰、九莲宝灯九面听、十三幺十三面听等）。
- 每种牌最多 4 张，手中已有 4 张的牌不再作为有效听牌。

## 出题方式

1. 先生成一手随机**胡牌**（标准型 / 七对 / 十三幺）。
2. 打掉其中一张，若剩余 13 张听 2~8 种牌，即成为一道多选题。
3. 选项 = 全部正确听牌 + 随机干扰牌（共约 10 个选项）。
4. 每局固定包含**九莲宝灯**（九面听）与**十三幺**（十三面听）两道经典题。

## 使用

直接用浏览器打开 `index.html`，或部署到任意静态服务器（如 GitHub Pages）。

```
mahjong-tingpai-quiz/
├── index.html   # 界面与交互（麻将桌主题 UI）
├── engine.js    # 胡牌/听牌判定与出题引擎（可独立复用）
└── README.md
```

## 玩法

每局 8 题：查看 13 张手牌 → 点击所有你认为"听"的牌 → 提交 → 查看正误与解析（听牌明细与面数）。全对为雀圣 🏆。
